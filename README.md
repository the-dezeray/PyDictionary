# PyDictionary

A feature-rich terminal dictionary application with pronunciation, synonyms, rhyming words, and interactive word games.

## Features

- 🔍 **Word Lookup**: Find definitions for any word
- 🔊 **Pronunciation**: Audio pronunciation using text-to-speech
- 📝 **Synonyms**: Find synonyms using WordNet
- 🎵 **Rhyming Words**: Discover words that rhyme
- 🔎 **Reverse Search**: Find words by their definitions
- 🎮 **Word Games**: Interactive quiz games and word guessing
- 🎨 **Rich Interface**: Beautiful terminal UI with Rich library

## Installation

```bash
pip install pydictionary
```

## Usage

Run the application:

```bash
pydictionary
```

### Commands

- Type any word to get its definition
- Use Tab to navigate between different modes
- Press Space to activate voice pronunciation
- Press Esc for settings

## Requirements

- Python 3.9+
- Internet connection for pronunciation and some features
